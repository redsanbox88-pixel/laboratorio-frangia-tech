# Laboratorio FranGia Tech

Una herramienta gratuita para abrir, leer y probar scripts de Python en un entorno aislado. Versión **0.9 Beta** para Windows de 64 bits.

## Descargar

La descarga oficial está en [la página de Laboratorio de FranGia Tech](https://frangiatech.com.ar/laboratorio). También podés bajar el ZIP desde la sección [Releases](https://github.com/redsanbox88-pixel/laboratorio-frangia-tech/releases).

**Contraseña del ZIP:** `FranGiaLab-2026!`. Se extrae con [7-Zip](https://www.7-zip.org/); Windows puede no abrir ZIP cifrados con AES-256 de forma nativa.

Después de extraerlo completo, abrí `bin/Laboratorio.exe`.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Docker Desktop instalado y abierto para ejecutar scripts. La primera vez Laboratorio construye su imagen de Python y necesita internet.
- Sin Docker podés abrir y leer scripts, pero no ejecutarlos.
- La PC descartable es opcional y requiere Windows Sandbox y Python instalado.

El aislamiento reduce riesgos, pero no garantiza seguridad absoluta frente a código malicioso. El ejecutable identifica a **FranGia Tech** como fabricante, aunque todavía no cuenta con una firma digital de editor verificado por Windows.

La descarga es gratis. Si querés colaborar, la donación voluntaria por Mercado Pago se explica en la página de descarga; no es requisito para bajar ni usar el programa.
